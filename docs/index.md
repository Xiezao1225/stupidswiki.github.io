# stupidswiki

> 一群人，一堆没什么用的知识，和一台记性不太好的服务器。

这里记录我们这伙人的**人、事、梗和传说**。写下来只是为了以后有据可查——毕竟大家的记性都不太好，而群里每天都在创造新的历史。

> [!note] 三条底线
> 只写乐子，不写隐私；可以损，不搞人身攻击；拿不准的先挂「待考证」。

## 三条不成文的规定

1. **只写乐子，不写隐私。** 真名、住址、单位这类东西，永远不进 wiki。
2. **可以损，不搞人身攻击。** 判断标准很简单：当事人看到之后会不会笑。
3. **拿不准就标「待考证」。** 传得太离谱的故事，先留着，等有人能证实。

## 这个站怎么跑起来的

本站是 [MkDocs](https://www.mkdocs.org/) + [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/) 构建的静态站：

| 位置 | 作用 |
| :--- | :--- |
| `mkdocs.yml` | 站点配置、导航、主题、Markdown 扩展 |
| `docs/` | 所有页面，一个 `.md` 一页 |
| `hooks/wiki.py` | 把 `{{模板}}`、`[[内链]]`、`> [!note]` 翻译成 Material 的提示块 |
| `hooks/notices.json` | 提示条模板库 |
| `legacy/` | 迁移前的自研静态站，留着当存档 |

本地预览：

```bash
python -m mkdocs serve
```

推送到 main 之后由 GitHub Actions 构建并发布，不需要手动跑构建。
