# 页首模板一览

页面顶上那些「本页正在施工」之类的横幅，写法是在 Markdown 里单独占一行：

````markdown
{{施工中}}
````

需要换一句话说，就用竖线接上自己的文字：

````markdown
{{施工中|这页写到一半，先别引用。}}
````

模板的标题、说明、类型都在 `hooks/notices.json` 里定义，改一处，全站所有用到它的页面一起变。

> [!note] 和正文提示块的区别
> 提示条描述**整页**的状态，正文提示块（`!!! note`）描述**某一段**。两者其实是同一个组件，配色和图标都跟着主题走。

## 自己写一条

不想用模板库，也可以直接在文件顶部手写字段，标题和说明都由你定：

````markdown
---
notice:
  type: warning
  title: 本页还在施工
  text: 内容随时可能变动，看到错漏欢迎直接改。
  variant: alert
---

# 页面标题
````

`type` 决定配色和图标：`note`（蓝）、`tip`（青绿）、`warning`（橙）、`danger`（红）。加 `variant: alert` 会多一个 LIVE 徽标。

## 往模板库里加一条

编辑 `hooks/notices.json`，在合适的分类下加一个对象：

```json
{
  "name": "还没定论",
  "kind": "warning",
  "title": "这事还没有定论",
  "text": "两种说法都有人信，先把两边都记下来。"
}
```

`name` 就是 `{{}}` 里写的名字。加完重新构建，`{{还没定论}}` 立刻可用。

## 写错了会怎样

模板库里找不到的名字不会被吞掉，会显示成一个红色虚线框：

{{这个模板不存在}}

这样一眼就知道是名字拼错了，还是忘了往 `notices.json` 里加。
