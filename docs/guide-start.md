# 怎么用这个 wiki

站点是静态生成的：`docs/` 下的 Markdown 由 MkDocs 编译成一堆 HTML，没有数据库，也没有后端。

## 找东西

1. **左侧导航**按栏目分组，点开即读。
2. **搜索**是全文的：点右上角的搜索框，或者直接按 <kbd>/</kbd>，输入标题或正文里的任意词。中文能搜——试过搜「表格」能命中。
3. **右侧目录**列出当前这页的二级、三级标题，滚动时跟着高亮。
4. 每页底部有**上一页 / 下一页**，按导航顺序一路读下去。

## 快捷键

| 按键 | 作用 |
| :--- | :--- |
| <kbd>/</kbd> | 聚焦搜索框 |
| <kbd>↑</kbd> <kbd>↓</kbd> | 在搜索结果里移动 |
| <kbd>Enter</kbd> | 打开选中的结果 |
| <kbd>Esc</kbd> | 关闭搜索 |

## 分享某一节

鼠标移到标题上，右边会冒出一个 `¶`，点它地址栏就带上这一节的锚点。把地址发给别人，打开就停在那一节。

比如「Markdown 速查」里的表格一节，地址是 `/guide-markdown/#表格`。

## 手机上也行

窄屏下左侧导航收进左上角的汉堡按钮，右侧目录折叠到正文上方；表格会横向滚动，不会撑破页面。

## 深浅色

右上角的太阳／月亮按钮在深色和浅色之间切换，选择记在这台机器的浏览器里。第一次打开时跟随系统设置。

## 想改内容

站名、导航、主题都在根目录的 `mkdocs.yml`；内容和写法见 [[guide-add-page]] 和 [[guide-markdown]]。
