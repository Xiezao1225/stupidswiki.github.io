# 条目模板

写新条目时，把下面这一整块复制过去，按提示替换掉占位文字，删掉用不上的小节。

````markdown
# 化名

> 一句话总结这个人。最好是他说过的话，或者别人对他的评价。

## 档案

| 项目 | 内容 |
| :--- | :--- |
| 化名 |  |
| 活跃年份 |  |
| 出没地点 |  |
| 关键词 |  |

## 来历

第一次出现是什么时候、什么场合。有截图就放截图，没有就写「据回忆」。

## 经典片段

### 片段一

时间、地点、当时发生了什么。写清楚「为什么好笑」，别只留下一句内部人才能懂的梗。

> 「当时他说的话」

### 片段二

同上。

## 常被引用的话

> 「……」

## 相关条目

- [[entry-sample]]
- [[guide-markdown]]

## 待考证

- 传说……（目前没有证据，谁有截图谁说话）
````

## 填写提醒

- **别写真名、住址、单位、家人的信息。** 模板里所有字段都只接受化名和公开场合的言行。
- **写清「为什么好笑」。** 内部梗最大的问题是三个月后连当事人自己都不记得了。
- **拿不准的先放「待考证」。** 留白比写错强。
- **相关条目至少留一条。** 孤立的页面没人会点进去。

> [!note] 关于篇幅
> 一条 300 到 800 字比较合适。太长了没人看，太短了像记事本。真有讲不完的故事，拆成「XX 某人 · 事件簿」单独一页。

## 别忘了登记

复制完记得在 `mkdocs.yml` 的 `nav:` 里加一行，否则它不会出现在左侧导航里：

```yaml
nav:
  - 人物志:
      - 示例条目：老王: entry-sample.md
      - 老张: people-zhang.md
```
