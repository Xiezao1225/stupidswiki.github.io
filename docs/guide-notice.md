# 提示条的写法

提示条就是页面顶部那种「本页正在施工」「含剧透」的横幅。在 Material 里它就是一个**提示块**（admonition），三种写法从省事到灵活：

| 写法 | 长什么样 | 什么时候用 |
| :--- | :--- | :--- |
| `{{模板名}}` | 标题、说明全部来自模板库 | 常用状态，十四个现成的够用 |
| `{{模板名\|自定义说明}}` | 标题沿用模板，说明换成你的 | 同一状态但每次要说的话不同 |
| front matter 手写 | 完全自己定 | 一次性提示，不打算复用 |

## 一、直接调模板

在正文里**单独占一行**写：

````markdown
{{施工中}}
````

渲染出来是这样：

{{施工中}}

想换说明就接一条竖线：

````markdown
{{施工中|这页写到一半，先别引用。}}
````

{{施工中|这页写到一半，先别引用。}}

模板名必须在 `hooks/notices.json` 里有，否则会显示成红色虚线框（见本页最下面的例子）。

## 二、写在文件顶部

front matter 里的 `notice` 可以写模板名，也可以写列表：

````markdown
---
notice:
  - 施工中
  - 有争议
---

# 页面标题
````

这样提示条出现在**正文最上面**。想给某一条换个说法，写成 `- 施工中: 这页只有开头。`——模板库只是个默认值。

## 三、完全手写

不进模板库、只在这一页用的一次性提示：

````markdown
---
notice:
  type: warning
  title: 本页还在施工
  text: 内容随时可能变动，看到错漏欢迎直接改。
---
````

字段说明：

| 字段 | 说明 |
| :--- | :--- |
| `type` | 提示块类型：`note`（蓝）、`tip`（青绿）、`warning`（橙）、`danger`（红），默认 `note` |
| `title` | 粗体标题，不写就用类型的默认名字 |
| `text` | 正文，支持行内 Markdown 和 `[[内链]]` |
| `variant` | 写 `alert` 会在标题后面挂一个 `LIVE` 徽标（`突发新闻` 用的就是这个） |

图标不用管——Material 按类型自动配，`note` 是 ℹ️、`tip` 是 💡、`warning` 是 ⚠️、`danger` 是 ❌ 那一套。

## 和正文提示块的关系

现在它们是同一个东西。模板和 front matter 最后都会被 `hooks/wiki.py` 翻译成标准的 `!!! note "标题"`，所以配色、图标、字体全都跟着主题走，你甚至可以混着写：

````markdown
!!! warning "手动写的"
    这一段是原生 Material 语法。

{{施工中|这一段来自模板库}}
````

区别只在**位置和用途**：模板适合「整页状态」，原生 `!!!` 适合「某一段的注解」。

## 两个坑

> [!warning] 少了结尾的 `---`
> 文件开头写了 `---` 却忘了在末尾再写一条，整段元数据会被当成正文渲染出来——页面顶上会出现一堆 `notice:` 字样。

> [!note] 只支持两层结构
> front matter 解析走的是 MkDocs 的 YAML，正常写法都行；`hooks/notices.json` 是纯 JSON，别写注释、别留尾逗号。

## 名字写错的样子

{{这个模板不存在}}

看到这种红色虚线框，就是模板库里没有这个名字——要么拼错了，要么还没加。
